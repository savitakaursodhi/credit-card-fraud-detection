# Dataset Information

**Dataset:** Credit Card Fraud Detection

**Source:** Kaggle

**Download link:** https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

**Description:** The dataset contains 284,807 credit card transactions, with 492 fraudulent transactions.

**Target variable:** Class

- 0 = Genuine transaction
- 1 = Fraudulent transaction

Download the dataset from Kaggle and place the CSV file in this folder before running the notebook.
