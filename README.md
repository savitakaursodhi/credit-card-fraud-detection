# Credit Card Fraud Detection Using Machine Learning
## Project Overview
This project uses Machine Learning to identify fraudulent credit card transactions.
## Dataset
- Dataset: Credit Card Fraud Detection
- Total transactions: 284,807
- Features: 30
- Target variable: Class
- 0 = Genuine transaction
- 1 = Fraudulent transaction
## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Random Forest Classifier
## Project Methodology
1. Data collection
2. Data preprocessing
3. Exploratory Data Analysis
4. Model development using Random Forest
5. Model evaluation
6. Fairness audit
## Fairness Audit
The model is evaluated across low, medium and high transaction amount groups using:
- Selection Rate
- True Positive Rate
- False Positive Rate
## Repository Structure
- src/ – Python scripts
- notebooks/ – Jupyter Notebook
- data/ – Dataset information
- models/ – Saved machine learning models
## How to Run
1. Download the dataset from Kaggle.
2. Install the required libraries using requirements.txt.
3. Open the Jupyter Notebook.
4. Run the notebook cells sequentially.
